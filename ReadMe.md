# Customer Churn Prediction

### Overview
This project predicts customer churn using Machine Learning techniques in Python. The model analyzes customer data to identify who is likely to stop using a service, helping businesses improve retention.

### Technologies Used
- Python  
- pandas, NumPy, scikit-learn  
- Matplotlib, Seaborn  
- Jupyter Notebook (Google Colab)

### Project Workflow
1. Data Cleaning and Preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Feature Encoding and Model Building  
4. Model Evaluation (Accuracy, ROC-AUC, Confusion Matrix)  
5. Feature Importance Visualization  

### Results
- Random Forest achieved around **90% accuracy**  
- Important churn indicators identified: *Contract Type*, *Tenure*, and *Monthly Charges*

### Files
- `CustomerChurnPrediction.ipynb` – main notebook  
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` – dataset  
- `requirements.txt` – dependencies  
- `images/` – plots and visual outputs
